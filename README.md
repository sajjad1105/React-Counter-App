
# ⚛️ React Counter App
A simple yet elegant Counter Application built using React.js and Hooks (useState). This app allows users to increment, decrement, and reset a counter value within a defined range. It also features dynamic button disabling, limit warnings, and a modern glassmorphic UI for an engaging experience.

## 🚀 Features

- 🔢 Increase or decrease the count
- ♻️ Reset the count to zero
- 🚫 Prevent going below 0 or above 100
- ⚠️ Show friendly limit messages (no pop-ups!)
- 🔒 Disable buttons at max/min limits
- 🎨 Clean and responsive UI

---

## 🛠️ Tech Stack

- **React** (via Create React App or Vite)
- **JavaScript (ES6+)**
- **CSS3** for styling

## 🧑‍💻 How to Run Locally

# Clone the repository
->git clone https://github.com/sajjad1105/React-Counter-App.git

# Navigate into the project folder
->cd counter-app

# Install dependencies
->npm install

# Start the React app
->npm start
->The app will run locally on http://localhost:3000
